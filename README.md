# bekzhan.com

Personal portfolio. Plain HTML + CSS, hosted on GitHub Pages.

| What to change | Where |
|---|---|
| Name, intro, About text, links, email | `index.html` — search for `✏️` |
| Colors, font | `css/style.css` — top `:root` block |
| Project cards | `index.html` — Projects section |
| A project's own page | copy `projects/project-template.html` |
| Images | `assets/img/` |
| 3D models (.glb) | `models/` |

Preview locally: just double-click `index.html`.
